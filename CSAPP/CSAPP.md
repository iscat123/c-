> | 层           | 典型容量      | 延迟数量级         | 备注                   |
> | ------------ | ------------- | ------------------ | ---------------------- |
> | 寄存器       | 数百 B        | ~0.3 ns            |                        |
> | L1 cache     | 32~64 KB      | ~1 ns（约 4 周期） | SRAM                   |

### 6.1：存储技术

#### 6.1.1：随机访问存储器
> 随机访问存储器分为两类：静态的（SRAM）和动态的（DRAM）， SRAM 用来作为高速缓存， DRAM用作主存。



##### 1.静态RAM

- SRAM 存储器由六个晶体管组成，具有双稳态特性，只要有电就能永远保持它的值。

##### 2.动态RAM

- DRAM由一个电容和一个晶体管组成。电容容易漏电，存储单元10~100 ms 内就会失去电荷，需要在 ms 级刷新电容。
- SRAM 与 DRAM 的区别![](.\image\SRAM与DRAM的区别.png)

##### 3.传统的DRAM

- 内存控制器（一种电路），连接 CPU 和 DRAM 芯片（引脚 pin 连接 ）。
- DRAM 芯片的基本构成单元是 DRAM 芯片单元（存储一个比特位），DRAM 芯片是由超单元（由 8 个DRAM芯片单元构成）组织而成的二维阵列。![](.\image\DRAM芯片视图.png)
- 读写超单元的流程：行地址（RAS ，行访问请求）→ 整行进行缓冲区 → 列地址（CAS ，列访问请求） → 取出目标超单元。![](.\image\读写超单元的流程.png)

##### 4.内存模块

- 多个 DRAM 芯片焊内存模块上，插入主板扩展槽上。内存控制器一次访问各 DRAM 芯片，并行取出 8 位，组成 64 位。

##### 5.增强的DRAM

- 为了 DRAM 能跟上 CPU 的速度，对传统 DRAM 进行优化，提高 DRAM芯片单元的访问速度。
- FPM → EDO → 同步 DRAM （SDRAM）→ DDR SDARM 。

##### 6.非易失性存储器

- ROM （只读存储器，部分也可读写）： PROM / EPROM / EEPROM / flash （闪存）/ SSD 。存储在 ROM 中的程序称为固件。

##### 7.访问主存

- 一次读事务的完整流程：CPU 发地址 → 总线 → 内存控制器 → 行地址激活 → 列地址 → 数据回传总线。





#### 6.1.2：磁盘存储

##### 1.磁盘构造

- 磁盘（ disk ）是由一个或多个盘片组成的。盘片的两面有磁性材料，表面由一组成为磁道的同心圆组成，每个磁道由多个之间存在间隔的扇区组成，每个扇区有512个字节。柱面是所有到主轴距离相等的磁道的集合。![](D:\CG-DOC\c-\CSAPP\image\磁盘构造.png)

##### 2.磁盘容量

- 磁盘容量 = 每个扇区的字节数 * 每个磁道的扇区数 * 每个表面的磁道数 * 每个盘片的表面数（常量 2 ）* 每个磁盘的盘片数
- 多区记录技术：把多组柱面分为一个纪录区，每个记录区中的磁道的扇区数由最靠主轴的磁道的扇区数决定。

##### 3.磁盘操作

- 磁盘是以扇区大小的块来读写数据的。
- 对扇区的访问时间 = 寻道时间（3 ~ 9 ms ） + 旋转时间（大约 4 ms ）+ 传送时间（大约 0.02 ms ）。
- 磁盘的访问时间大约 10 ms ，是 SRAM （ 64 位 4 ns）的 40000 倍，是 DRAM （64 位 60 ns ）的 2500 倍。

##### 4.逻辑磁盘块

- 逻辑块寻址（ LBA ），物理盘面 + 磁道 + 扇区，三元组确定唯一的 LBA 。

##### 5.连接 I/O 设备

- I/O 设备通过 I/O 总线连接到 CPU 和 主存。 I/O总线一般是 PCIE （高速外围设备互连标准）。

##### 6.访问磁盘

1.  CPU 经 MMIO （内存映射 I/O ） 写控制器寄存器:
        命令=READ,起始 LBA=819200,扇区数=8,主存缓冲区地址=P,方向=盘→内存
2.  CPU 转身去干别的(★DMA 的全部意义:搬运期间 CPU 零参与)
3.  控制器寻道+等待旋转,整扇区读出进控制器缓冲区
4.  控制器(作为总线主控)发起 DMA:数据从设备缓冲区 → 主存地址 P,不等 CPU
5.  全部扇区完成,控制器向中断控制器发出中断请求
6.  中断控制器判定路由,投递给某个 CPU 核心
7.  CPU 在当前指令执行完后响应:保存上下文 → 查中断向量表(IDT)
        → 跳入驱动注册的中断服务程序(ISR)
8.  ISR 检查完成状态、标记请求完成(比如唤醒阻塞在 read() 上的线程)
9.  中断返回,恢复原程序执行





#### 6.1.3：固态硬盘

- 闪存翻译层（FTL）+ 闪存块（块由页组成）；读/写以**页**为单位，擦除以**块**为单位，页写前必须先擦整块。

## 做笔记的思路

你之前采纳过“三层判据”，笔记就把它固化下来。**每个 h5 的笔记模板**：

1. **一句话复述**——它是什么（必须用自己的话，禁止抄书）
2. **为什么存在**——它解决什么问题，没有它会怎样
3. **对写代码意味着什么**——能答就写，答不出就空着标 `??`，留给实验回填

句数分配上，用“影响我写代码的决策吗”这一条把内容分成三类，正好对应你的重点/非重点规则：

- **机制描述类**（DRAM 超单元、内存模块、磁盘构造）：一句话 + 关键词，别恋战。这类内容是给后面章节垫场的，当字典用。
- **决策影响类**（局部性、地址划分、缓存友好代码、分块）：3~5 句，且必须包含**判据**——“怎么算”“怎么选”“什么时候失效”，这是笔记的价值所在。
- **图表数字类**（超单元阵列图、地址划分图、存储山、各层延迟数量级）：抄图或画 ASCII，数字抄表。这类内容文字描述不了，图本身就是笔记。

另外四条规则：

- **记算例，不记规则**。像 6.4 的地址划分（tag/组索引/块偏移），规则罗列三月后看不懂，一道完整算例（题目→步骤→答案）永远看得懂。
- **节末允许加一行“串讲”**。h5 是碎片，而 6.4 的精华恰恰是横向对比（三种映射方式、两种写策略），在节末补一张对比表不算改结构，是拼图。
- **6.1 快扫，把预算留给 6.4~6.6**。你现在大纲展开的是 6.1，它是全书“了解即可”密度最高的一节——大部分 h5 一句话就能过，别在这里耗尽热情；真正的硬仗（地址划分、缓存友好、分块）在后面。
- **验收标准**：三个月后只看笔记能复述出每节大意。写的时候心里想着“这是写给三个月后的自己的”，自然不会抄书。
